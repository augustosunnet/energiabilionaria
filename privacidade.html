O que é o Fabrica EB

O Fabrica EB é uma ferramenta de uso interno do Energia Bilionária. Ela serve apenas para enviar vídeos produzidos por nós às contas do próprio Energia Bilionária no YouTube, no Instagram e no TikTok. Não é oferecida ao público e não coleta dados de outras pessoas.

Dados que acessamos

  • YouTube: a permissão youtube.upload, usada somente para enviar vídeos ao canal do Energia Bilionária e definir título, descrição e horário de publicação.
  • Instagram e TikTok: as permissões de publicação de conteúdo, usadas somente para publicar vídeos nas contas do Energia Bilionária.

Não lemos, guardamos nem compartilhamos dados de espectadores, seguidores, mensagens ou de qualquer outro usuário.

Como os dados ficam guardados

Os tokens de acesso ficam apenas no computador onde a ferramenta roda, fora de qualquer servidor público, e são usados só para as publicações. Nada é vendido ou repassado a terceiros.

Uso dos Serviços de API do YouTube

O Fabrica EB usa os Serviços de API do YouTube. Ao usá-lo você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google. O acesso pode ser revogado a qualquer momento em security.google.com/settings/security/permissions.

Exclusão

Para apagar os dados guardados, basta revogar o acesso no link acima; a ferramenta deixa de funcionar e o token guardado se torna inútil e é apagado.
